With an agent

Install the skill, then say “use project-foundation to bootstrap this repository”. The agent looks first, sends one message with what it found and the choices it proposes, waits for your answer, and shows the file list before it writes.

npx skills add bhoudebert/my-skills

From the command line

Run it from the repository. It detects the stacks and your GitHub remote, asks the rest, and shows what it would write. Nothing needs installing, and it needs Node 22 or later.

npx github:bhoudebert/my-skills init --dry-run
